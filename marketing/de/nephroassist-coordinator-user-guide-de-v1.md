## Einführung

Willkommen bei NephroAssist — der ersten Plattform für die Vor-Transplant-Koordination in Italien. Dieses Handbuch führt Sie Schritt für Schritt durch die Plattform. Es ist für Koordinatoren mit moderatem Digitalisierungsgrad geschrieben und enthält Screenshots, Beispiele und einen Abschnitt zu häufigen Problemen.

**Voraussetzungen:**
- Zugangsdaten von Ihrem NephroAssist-Ansprechpartner
- Ein internetfähiges Gerät (Computer, Tablet oder Smartphone)
- Grundkenntnisse in der Verwendung von E-Mail und Browser

---

## 1. Anmeldung und Dashboard-Übersicht

### 1.1 Erste Anmeldung

1. Öffnen Sie nephroassist.com in Ihrem Browser.
2. Klicken Sie auf „Accedi" (Anmelden).
3. Geben Sie Ihre E-Mail-Adresse und Ihr temporäres Passwort ein.
4. Sie werden aufgefordert, ein eigenes Passwort zu erstellen.
5. Bestätigen Sie Ihre Einwilligung zur Datenverarbeitung (GDPR Art. 9).

**Tipp:** Speichern Sie die Login-Seite als Lesezeichen.

### 1.2 Das Dashboard

Nach der Anmeldung sehen Sie das Dashboard:

| Bereich | Funktion |
|---------|----------|
| **Patienten in Evaluation** | Alle Patienten, die sich gerade in der Vor-Transplant-Phase befinden |
| **Warteliste** | Patienten, die alle Untersuchungen abgeschlossen haben und auf ein Organ warten |
| **Aufgaben heute** | Benachrichtigungen, anstehende Termine, abgelaufene Dokumente |
| **Berichte** | CNT-kompatible Exporte und Statistiken |
| **Nachrichten** | Chat mit Patienten und interne Team-Kommunikation |

## 2. Patienten-Onboarding

### 2.1 Einen neuen Patienten anlegen

1. Klicken Sie auf „Nuovo paziente" (Neuer Patient).
2. Füllen Sie die Stammdaten aus: Name, Geburtsdatum, Kontaktdaten, Tessera sanitaria-Nummer.
3. Weisen Sie den Patienten einer Phase zu (Evaluation, Warteliste, etc.).
4. Der Patient erhält automatisch eine Willkommens-E-Mail mit Login-Daten.

**Wichtig:** Der Patient muss seine Einwilligung (GDPR Art. 9) digital abgeben, bevor Daten verarbeitet werden.

### 2.2 Angehörige hinzufügen

1. Öffnen Sie das Patientenprofil.
2. Klicken Sie auf „Aggiungi familiare".
3. Geben Sie Name, Beziehung und Telefonnummer ein.
4. Legen Sie fest, ob der Angehörige Benachrichtigungen erhalten soll.

---

## 3. Checklisten verwalten

### 3.1 Checklisten erstellen

1. Wählen Sie einen Patienten aus.
2. Klicken Sie auf „Nuova checklist".
3. Wählen Sie aus den Vorlagen (Evaluation, Warteliste, Post-Transplant).
4. Passen Sie die Aufgaben an die Anforderungen Ihres Zentrums an.
5. Weisen Sie Fristen und Verantwortliche zu.

### 3.2 CNT-kompatible Checklisten

NephroAssist enthält vordefinierte Checklisten, die den CNT-Anforderungen entsprechen:
- Blutuntersuchungen (3 Monate Gültigkeit)
- Herzuntersuchung (6 Monate)
- Zahnärztliche Untersuchung (3 Monate)
- Psychosoziales Gespräch (12 Monate)
- Infektionsscreening (6 Monate)

**Tipp:** Sie können eigene Aufgaben hinzufügen, die spezifisch für Ihr Zentrum sind.

---

## 4. Dokumentenüberprüfung

### 4.1 Hochgeladene Dokumente prüfen

1. Klicken Sie auf „Documenti" im Patientenprofil.
2. Wählen Sie das hochgeladene Dokument aus.
3. Prüfen Sie Qualität und Vollständigkeit.
4. Akzeptieren Sie („Approva") oder lehnen Sie („Rifiuta") das Dokument ab.
5. Bei Ablehnung: Geben Sie einen Grund an und fordern Sie eine neue Einreichung an.

### 4.2 Dokumente exportieren

1. Wählen Sie den Patienten aus.
2. Klicken Sie auf „Esporta documenti".
3. Wählen Sie das Format (PDF, ZIP).
4. Die Dokumente werden CNT-konform benannt und strukturiert.

---

## 5. Patient-Koordinator-Chat

### 5.1 Nachricht senden

1. Öffnen Sie das Patientenprofil.
2. Klicken Sie auf das Chat-Symbol.
3. Schreiben Sie Ihre Nachricht.
4. Der Patient erhält eine Push-Benachrichtigung und eine E-Mail.

**Tipp:** Verwenden Sie vordefinierte Nachrichten für häufige Anfragen („Bitte laden Sie den aktuellen Bluttest hoch", „Ihr Termin steht bevor").

### 5.2 WhatsApp-Integration (optional)

Falls Ihr Zentrum die WhatsApp Business API nutzt:
1. Verknüpfen Sie die Telefonnummer des Patienten.
2. Nachrichten werden parallel als WhatsApp-Nachricht gesendet.
3. Der Patient kann direkt antworten — die Antwort erscheint im NephroAssist-Chat.

---

## 6. CNT-Berichterstattung

### 6.1 Berichte generieren

1. Klicken Sie auf „Reportistica CNT".
2. Wählen Sie den Zeitraum.
3. Wählen Sie die Berichtsart:
   - Patienten in Evaluation
   - Auf der Warteliste
   - Transplantierte Patienten
   - Abgelehnte Patienten
4. Klicken Sie auf „Genera".
5. Der Bericht wird als CSV oder PDF exportiert.

### 6.2 Daten exportieren

1. Wählen Sie „Esporta dati".
2. Wählen Sie die Patientengruppe.
3. Der Export enthält alle CNT-relevanten Felder in der erforderlichen Reihenfolge.

## 7. Häufige Probleme („Problemi comuni")

| Problem | Lösung |
|---------|--------|
| Patient kann sich nicht anmelden | Passwort zurücksetzen; E-Mail-Adresse auf Tippfehler prüfen |
| Dokument ist zu unscharf | Patienten bitten, es erneut hochzuladen; minimale Auflösung: 300 DPI |
| Patient antwortet nicht auf Nachrichten | WhatsApp als alternativen Kanal nutzen; Angehörige kontaktieren |
| CNT-Export enthält Fehler | Alle Pflichtfelder prüfen; fehlende Dokumente ergänzen |
| Einwilligung ist abgelaufen | Patienten erinnern, die Einwilligung zu erneuern (GDPR Art. 9) |
